SAS Note1

By 可達 19 December 2024

今日SAS學習紀錄-編碼

1.將AAA複製到新的資料集 BBB，並將其編碼設置為 UTF-8
/*UTF-8*/
data BBB (encoding="UTF-8");
set AAA;
run;
2.將 Alib 資料庫中的所有資料集複製到 Blib 資料庫，並將編碼轉換為 UTF-8。
libname Alib cvp "c:\temp"; /*定義來源資料庫*/
libname Blib "c:\" outencoding="utf-8"; /*定義目標資料庫並設置編碼為UTF-8 */
proc copy noclone in=Alib out=Blib;
run;
Explain:

CVP引擎主要用於處理需要轉碼的SAS數據文件，因為不同字符集之間的轉碼可能會改變字符數據的長度，所以透過CVP擴展字符變量的長度來防止數據被截斷。

預設擴充是變數長度的1.5倍。

也可以指定擴充量libname inlib cvp 'c:\temp' cvpbytes=5;

cvpbytes=5擴展字符變量長度5個字節

ref： 我是ref超連結

proc copy noclone in=Alib out=Blib;

使用 PROC COPY 將 inlib 中的所有資料集複製到 outlib，並應用新的編碼。

NOCLONE 選項確保不複製資料集的屬性，只複製數據
